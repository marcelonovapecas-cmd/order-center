lista de comandos usados:

----------------------------------------

- git init         (iniciando Git na raiz do projeto)
- npm init      (iniciando projeto NodeJs dentro de backend)
- npm install --save-dev typescript   (instalando typescript como devdependencies no backend)
- npm install express   (isntalando express no backend)
-npm install dotenv  (pra carregar variaveis do .env)
-npm install prisma @prisma/client (instalando prisma no backend)
- npx prisma init (inicializando o prisma)
- npx prisma migrate dev --name init (após criar os modelos no schema, esse comando foi usado pra criar a migration)
- npx prisma generate
- npm install @prisma/adapter-pg pg (instalando driver PostgreSQL no prisma)
- npm install -D tsx (devido o "noEmit:true", o tsx precisa ser instalado para desenvolvimento)
- npm install bcrypt (instalando pacote de criptografia de senhas)
- npm install -D @types/bcrypt (instalando tipos do pacote acima)
- npm install zod (validador de dados)
- npm install jsonwebtoken
- npm install -D @types/jsonwebtoken

- npm install cors
- npm install -D @types/cors

ROTAS PARA TESTES: 

login:   POST  http://localhost:3000/auth/login
   [body] raw : {"email": "joao@email.com", "senha": "123456"}

ver pedidos:  GET http://localhost:3000/pedidos
   [header] Authorization : Bearer (token)

ver pedido específico:  GET   http://localhost:3000/pedidos/id
   [header] Authorization : Bearer (token)

criar pedido:  POST  http://localhost:3000/pedidos
   [header] Authorization : Bearer (token)

atualizar status do pedido:   PUT   http://localhost:3000/pedidos/id/status
   [header] Authorization : Bearer (token)
   [header] Content-Type : application/json
   [body] raw: {"status": "AGUARDANDO"}

adicionar itens no pedido: POST http://localhost:3000/pedidos/id/itens
   [header] Authorization : Bearer (token)
   [body] raw: {"nome": "nome do produto", "quantidade": quantidadeproduto}

atualizar itens no pedido: PATCH http://localhost:3000/pedidos/[pedidoId]/itens/[itemId]
   [header] Authorization : Bearer (token)
   [header] Content-Type : application/json
   [body] raw: {"nome": "novo nome", "quantidade": novaQuantidade}

deletar itens no pedido: DELETE http://localhost:3000/pedidos/[pedidoId]/itens/[itemId]
   [header] Authorization : Bearer (token)
